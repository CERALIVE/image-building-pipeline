# WHAT: the Rockchip RK3588 video userspace (MPP encode/decode
# library, RGA 2D accelerator, the GStreamer MPP plugin, and the multimedia udev
# suite-literal-ok(file): every `bookworm` here is a THIRD-PARTY pool name — the
# Armbian BSP feed and the radxa rk3588s2-bookworm pool — reached by exact pinned
# URL + SHA-256. None of them is the target rootfs suite, and repointing them at
# manifests/target-release.env would resolve to URLs that do not exist.
# config) that the Armbian bookworm arm64 feed does NOT ship. These make the SoC's
# HW encoders reachable from GStreamer (mpph264enc/mpph265enc/mppjpegenc/
# mppvp8enc register only when this MPP userspace is present). The GPU half of
# this set is gone — see the retirement note below.
#
# WHY PINNED URLs (not an apt source): these are NOT in a rotating apt repo we
# trust, so they are pinned to exact upstream release-asset URLs and verified by
# SHA-256 before staging — the SAME fail-closed, no-fallback discipline as the
# Armbian BSP fetch (lib/fetch-debs.sh fetch_bsp), minus the apt/GPG machinery
# (a pinned URL + SHA-256 needs no rotating index or GPG trust root). Do NOT turn
# any of these into a `deb [signed-by=...] https://...` apt line — that is a new
# live trust root and is exactly what this file exists to avoid.
#
# PROVENANCE: proven working on real Rock 5B+ hardware (raw H.264/H.265 HW encode
# via mpph264enc/mpph265enc, ffprobe-verified). The proven combination is
# tsukumijima MPP 1.5.0-1 plus the ABI-matched radxa GStreamer/RGA pair.
#
# FORMAT: one record per package, four whitespace-separated fields:
#   <package>  <filename>  <sha256>  <url>
#   * <package>  MUST equal the Debian Package: field — it is the family-manifest
#                wiring key AND the orchestrate.sh partition key.
#   * <filename> is the exact release-asset filename (== basename of <url>).
#   * <sha256>   is the real lowercase-hex SHA-256 of the exact asset.
#   * <url>      is the exact pinned download URL.
# Consumed by fetch_rk3588_userspace in lib/fetch-debs.sh. The set of <package>
# names here MUST match the userspace packages declared in the rk3588 family
# manifest (firmware_packages / hw_accel_gstreamer_plugins / gstreamer_runtime_packages):
# fetch_bsp EXCLUDES these names from the Armbian fetch, and fetch_rk3588_userspace
# fetches exactly the ones the resolved family declares.
#
# VERSIONS ARE EMPIRICALLY PROVEN — do not bump without re-proving on hardware.
# tsukumijima MPP 1.5.0-1 + CeraLive gstreamer1.0-rockchip-ceralive
# 1.14.4+ceralive.1 + radxa librga2 2.2.0-1 is the exact combination selected
# for the MPP encoders.

# --- Mali-G610 (Valhall) GPU userspace — RETIRED with the vendor kernel track ---
# `libmali-valhall-g610-g24p0-wayland-gbm` used to be pinned here. It is gone
# because it is ABI-bound to Rockchip's out-of-tree Mali module and its /dev/mali0
# node, which only the retired vendor 6.1 BSP kernel created. The mainline track
# binds the same silicon with the in-tree open `panthor` DRM driver and Mesa, and
# the blob's /etc/ld.so.conf.d/00-aarch64-mali.conf would capture libEGL.so.1 /
# libGLESv2.so.2 / libgbm.so.1 image-wide for a driver that cannot work. No
# variant declares it, so nothing would stage it either way — the pin is removed
# so a future reader cannot mistake a dead URL for a live GPU option. The exact
# pinned URL + SHA-256 remain recoverable at the `vendor-kernel-final` tag.
